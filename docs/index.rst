Nicomedia
=========

Nicomedia preserves numerical and catalog helper APIs used by older
astrophysical workflows. New shared numerical routines belong in TDpy, while
lensing and self-lensing implementations belong in Chalcedon. Existing
Nicomedia interfaces remain available for compatibility.
